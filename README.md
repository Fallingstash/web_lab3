# Менеджер задач на React (Лабораторная работа №3)

Учебный проект: приложение «Список задач» переписано с Vanilla JS (Л2) на React с добавлением маршрутизации и расширенного функционала.

- **Макет:** [Figma To-Do List](https://www.figma.com/design/U09ss0BkhIpaSLm05v0AQ7/To-Do-List-(Community))
- **Стек:** React 18, Vite, React Router DOM

## 🚀 Запуск проекта

Для запуска проекта локально выполните следующие команды в терминале:

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск сервера разработки
npm run dev

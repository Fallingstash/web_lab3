# Менеджер задач на React (Лабораторная работа №3)

Учебный проект: приложение «Список задач» переписано с Vanilla JS (Л2) на React с добавлением маршрутизации и расширенного функционала.

- **Макет:** [Figma To-Do List](https://www.figma.com/design/U09ss0BkhIpaSLm05v0AQ7/To-Do-List-(Community))
- **Стек:** React 18, Vite, React Router DOM

## 🚀 Запуск проекта

Для запуска проекта локально выполните следующие команды в терминале:

1. Установка зависимостей:
   `npm install`

2. Запуск сервера разработки:
   `npm run dev`

После запуска приложение будет доступно по адресу `http://localhost:5173/`.

## ✨ Реализованный функционал
- **Множественные списки:** создание и отображение задач в разных списках (Входящие, Работа, Дом).
- **Маршрутизация (React Router):** 
  - Переходы между списками без перезагрузки страницы.
  - Отдельная страница для каждой задачи (карточка задачи).
  - Страница 404 (Not Found) для несуществующих адресов.
- **Карточка задачи:** редактирование названия и описания, добавление/удаление подзадач, отображение прогресса (выполнено N из M).
- **Синхронизация статусов:** при отметке всех подзадач задача автоматически становится выполненной (и наоборот).
- **Фильтры:** отображение Все / Активные / Выполненные. Состояние фильтра сохраняется в URL (query params).
- **Поиск:** фильтрация задач по названию с задержкой (Debounce) в 300 мс для оптимизации рендера.
- **Смена темы:** светлая и темная темы. Выбор пользователя сохраняется в `localStorage`.

## 📂 Архитектура проекта
- `src/state/` — глобальное состояние (Context API + useReducer), редьюсер и логика хранилища.
- `src/pages/` — компоненты страниц (Layout, ListPage, TaskCard, NotFoundPage).
- `src/components/` — переиспользуемые UI-компоненты (TaskItem, TaskList, AddTaskForm).
- `src/hooks/` — кастомные хуки (`useDebounce` для поиска, `useLocalStorage` для темы).
- `src/router.jsx` — карта маршрутов приложения.

## 🗑️ Что удалено из кода Л2 (и почему)
При переходе на React были удалены следующие части кода:
1.  **Ручное изменение DOM:** удалены все вызовы `document.querySelector`, `createElement`, `appendChild`, `innerHTML`. В React мы управляем состоянием, а React сам перестраивает DOM.
2.  **Императивное управление событиями:** удалены `addEventListener` и делегирование событий через `closest()`. Теперь события передаются напрямую через атрибуты (например, `onClick`).
3.  **Ручная синхронизация с `localStorage`:** в Л2 сохранение вызывалось вручную после каждого действия. В React это вынесено в `useEffect` (и кастомный хук `useLocalStorage`).
4.  **Модуль `view.js`:** функция `render()` больше не нужна, так как React автоматически вызывает компоненты при изменении состояния.

## ⚖️ Принятые решения (расхождения с макетом)
1.  **Связь задачи с подзадачами:** Если все подзадачи выполнены, главная задача автоматически отмечается как выполненная. Если снять галочку с главной задачи, все подзадачи сбрасываются.
2.  **Поиск с задержкой:** Для предотвращения лишних перерисовок при вводе используется хук `useDebounce` (задержка 300 мс).
3.  **Тема:** Кнопка переключения темы вынесена в сайдбар. Начальная тема определяется системными настройками браузера.
